# PC Web 与终端交付记录（2026-09-05）

本轮范围：PC 浏览器适配、终端对话体验、安装方式与离线安装脚本。不增加独立桌面窗口，不推送远程仓库。

## 已实现

- Web 对话区域使用可收缩布局，避免输入框、发送按钮和会话操作被挤出可视区。
- 终端用 Rich 展示执行状态和回答，过程日志保留在日志文件；普通问答显示 Markdown 正文，研判报告使用面板。
- 上下方向键回看本次输入，Tab 补全斜杠命令；历史只存内存。
- `/history` 查看会话 ID，`/resume ID` 恢复自己可访问的会话，`/export 文件.md` 导出且不覆盖已有文件。
- 分析时 Ctrl+C 取消并返回输入；多行草稿中 Ctrl+C 丢弃草稿，避免误发送。
- JSON 模式继续保持原有单行 `case / decision / score` 协议。
- 离线安装脚本校验 wheel 数量、路径空格和失败退出码，不强制覆盖现有安装；PowerShell 脚本恢复调用者环境变量。
- README 区分“本地 wheel 安装”和“包含全部依赖的真正离线安装”。

## 使用本次终端更新

在项目目录，用运行项目的同一 Python 环境更新依赖：

```powershell
python -m pip install -r requirements.txt
python -m backend chat
```

已有其余依赖时，仅补输入组件即可：

```powershell
python -m pip install "prompt-toolkit>=3.0.43,<4"
```

缺少该组件仍可普通输入，但没有本轮内置按键增强。测试时组件只安装到项目隔离目录，没有修改用户全局 Python 环境。
