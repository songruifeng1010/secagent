# 模型目录

离线训练生成的模型文件（例如 `threat_model_xgboost_v1.joblib`）和对应的 `_report.json` 放在此目录。模型文件不由仓库预置；运行时找不到经过真实数据训练并验证的模型会明确报告“未部署”，不会自动生成或训练合成模型。

## 自动加载质量门禁

运行时只会自动选择同时满足以下最低指标的模型：

- `f1_score >= 0.50`
- `recall >= 0.20`
- `roc_auc >= 0.70`
- 训练/测试准确率差距 `<= 0.15`

未通过门禁的模型仍会在 `/api/ml/models` 中展示，便于审计和继续实验，但不会被威胁检测器自动加载。准确率不能单独作为入选条件，因为入侵数据通常存在类别不平衡。

当前 CSE-CIC-IDS2018 的 v3 是受限样本实验模型，召回率约为 0.01%，已被门禁明确排除；请完成类别/时间分布修正后再部署。
